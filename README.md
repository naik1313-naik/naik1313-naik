## 🚀 Selected Work

### 🏗️ [Rathod Brothers](https://github.com/naik1313-naik/rathod-brothers)
> Production full-stack platform — marketing site, MySQL enquiry pipeline, and an admin dashboard behind JWT auth.

- **TypeScript end to end** — React 18 + Vite storefront, Express + MySQL API
- **Production patterns** — JWT auth, Zod validation, rate limiting, Helmet
- **Quality gates** — Vitest + Supertest, ESLint, typecheck in one `verify` script
- npm workspaces monorepo, deployed on Railway

### 🔧 [GV Enterprises](https://github.com/naik1313-naik/gvplumbing)
> Premium Next.js showroom site with a real lead funnel for a plumbing & hardware business.

- Next.js 14 App Router, TypeScript, Tailwind v4
- Framer Motion transitions, count-ups, scroll reveals
- Supabase data + Resend email, React Hook Form + Zod forms

### 🛒 [SwadeshiMart](https://github.com/naik1313-naik/ecommerce-website)
> Full-stack ecommerce store — server-side sessions, checkout & orders, admin CRUD.

- FastAPI + SQLAlchemy + SQLite backend
- React storefront with search + filters
- The **Python** side of the team — clean docs and an accurate README

### 🎓 [College Management System](https://github.com/naik1313-naik/college-management-system)
> Role-based platform for Admin, Teacher and Student — each with its own permissions and UI.

- JWT role-based access control, PostgreSQL migrations
- Razorpay fee payments, shared API ready for React Native

### ☀️ [AI Energy Prediction](https://github.com/naik1313-naik/ai-energy-prediction)
> Trained a RandomForest regression model on household energy data and served it over the web.

- scikit-learn `RandomForestRegressor`, clean train/eval split
- Flask API serving a `.pkl` model, interactive charts
- Rule-based efficiency recommendations

### 🖥️ [Portfolio](https://naik1313-naik.github.io/portfolio.2/) · [Linways](https://github.com/naik1313-naik/linways)
> The creative side — scroll-driven 3D experiences.

- **Portfolio** — React 19, Three.js R3F hero, GSAP, Lenis, deployed on Pages
- **Linways** — Astro + React, scroll-reactive Three.js camera, glassmorphism
